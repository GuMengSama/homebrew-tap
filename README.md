# GuMengSama/homebrew-tap

Homebrew tap for [GuMengSama](https://github.com/GuMengSama)'s projects.

| Cask | What it is |
|---|---|
| `mpv-wrapper` | [mpv-wrapper](https://github.com/GuMengSama/mpv-wrapper): a real `mpv.app` for the Homebrew `mpv` formula |

```sh
brew tap GuMengSama/tap
brew trust --cask GuMengSama/tap/mpv-wrapper   # Homebrew 7 asks you to trust third-party casks
brew install --cask mpv-wrapper
```
